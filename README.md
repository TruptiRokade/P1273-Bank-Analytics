# Banking Data Analytics

## Project Overview

P1273 Bank Analytics is a Business Intelligence project developed to analyze banking loan and transaction data using Excel, Python, MySQL, Tableau, and Power BI.

## Objectives

- Analyze loan performance
- Monitor customer transactions
- Track KPIs
- Generate business insights
- Support data-driven decision making

## Technologies Used

- Excel
- Python
- MySQL
- SQL
- Tableau
- Power BI
